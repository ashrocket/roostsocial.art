# Logos

## RoostDraw.icns

- What it is: the RoostDraw Mac app icon, copied with `cp` from controller/RoostDraw/Resources/RoostDraw.icns. Not redrawn, not re-encoded. No PNG or SVG of it exists in the project.
- Not the gallery logo. The gallery's mark is the dove emoji in the header (site/src/index.js:54). The emoji is left out of the Hero preview.
- Ink colour: none. The icon is multi-colour. Its colours are the pixel values of this file and are not defined in any source file, so no exact value is cited. Do not use the icon colours as tokens.
- Minimum size: not defined in the source. The icns holds a 1024 px largest slot; the smallest is 16 px.
- Use: Mac app and dock contexts only. The icon is not a web logo.
